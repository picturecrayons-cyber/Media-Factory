# LOOP KIDS CMS Phase 1

## Boundary
- Bridge remains the authority for rights, licensing, territory/language windows, approvals and distribution authorization.
- LOOP KIDS is a Loop consumer sub-brand and merchandising surface.
- No second Supabase project.

## Phase 1 controls
- Kids catalog
- Hero / featured
- Collections
- Age bands
- Languages
- Publish / unpublish
- Scheduling
- Artwork
- Kids-safe contextual ad slots

## Advertising safety
Allowed: contextual kids/family campaigns that do not rely on child profiling.

Blocked by default:
- behavioral/personalized targeting of children
- gambling
- alcohol
- dating
- adult content
- financial products
- other adult-only categories

## Data
This PR is UI shell only. It does not apply a database migration or mutate production data.
